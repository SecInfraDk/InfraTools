# PingCastle

## Purpose

Provides checks and remediation for specific PingCastle findings.

## Example contents

Scripts that map a check or change to a rule and can verify the finding after remediation.

## Scope

General AD assessment and hardening belong in `../../ActiveDirectory`. Keep environment reports outside the repository.

## Dependencies

Requires the relevant finding or report data and access to the AD objects or policies covered by the check.
