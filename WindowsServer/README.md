# WindowsServer

## Purpose

Provides general operations tools for existing Windows Server installations.

## Example contents

Service checks, event log diagnostics, and server status exports.

## Scope

Role-specific tools for AD DS, DHCP, DNS, or PKI belong in their corresponding folders. OS preparation belongs in `InfraAsCode`.

## Dependencies

Requires access to Windows Server and permissions for the relevant service, log, or remote connection.
