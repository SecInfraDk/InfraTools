# DHCP

## Purpose

Administers and assesses existing Windows DHCP servers.

## Example contents

Checking scope utilization, exporting leases, and maintaining reservations.

## Scope

Role installation and initial configuration belong in `InfraAsCode/BuildScripts/Services/DHCP`.

## Dependencies

Requires access to the DHCP server, the DhcpServer module for its cmdlets, and appropriate permissions.
