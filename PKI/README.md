# PKI

## Purpose

Supports operation, assessment, and maintenance of an existing PKI.

## Example contents

Monitoring certificate expiration, checking CRL publication, and reviewing CA health.

## Scope

CA installation belongs in `InfraAsCode/BuildScripts/Services/PKI`. Manage private keys and credentials outside the repository.

## Dependencies

Requires access to the relevant CAs or publication points and permissions for the individual operation.
