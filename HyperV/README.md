# HyperV

## Purpose

Administers existing Hyper-V hosts and virtual machines.

## Example contents

VM inventory, checkpoint checks, and diagnostics for virtual storage or networking.

## Scope

Reusable provisioning and configuration of new VMs belong in `InfraAsCode/Platforms/HyperV`.

## Dependencies

Requires access to the Hyper-V hosts, the Hyper-V PowerShell module, and the relevant permissions.
